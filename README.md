# 🚀 July Landing Zone 2026

A production-ready Terraform project designed to deploy and manage cloud infrastructure using a modular and scalable architecture.

## 📌 Project Overview

This repository demonstrates Infrastructure as Code (IaC) best practices using Terraform. The project follows a parent-child module architecture, making the infrastructure reusable, maintainable, and easy to extend.

- 🔄 Reusable Infrastructure Components
- 🔒 Secure and Scalable Design

- 📖 Well-Documented Configuration

## 🚀 Getting Started

Initialize Terraform

```bash
terraform init
```

Validate Configuration

```bash
terraform validate
```

Preview Infrastructure

```bash
terraform plan
```

Deploy Infrastructure

```bash
terraform apply
```

Destroy Infrastructure

```bash
terraform destroy
```
